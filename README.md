## 🎯 About

I kept wasting hours scrolling through generic design galleries—beautiful work, but nothing I could realistically build.

**INSPOSITE** is a curated collection of websites, portfolios, and tools that are evaluated for **buildability**, not just visual appeal.

If you code, design, or do both—this is inspiration you can actually use.

---

## ✨ What You'll Find

- **Portfolios** — Developer & designer portfolios worth studying
- **Inspiration** — Real-world websites with smart, practical design decisions
- **Tools** — UI libraries, AI tools, and utilities builders actually use
- **Quality over quantity** — Every entry is manually reviewed

No fluff. No clones. Just useful references.

---

## 🛠️ Built With

- **Next.js 15** (App Router) — Server Components & modern architecture  
- **Tailwind CSS v4** — High-performance styling engine  
- **Framer Motion** — Smooth, declarative animations  
- **TypeScript** — Type-safe, scalable codebase

## 🚀 Run Locally

If you want to see how the project is structured or run it on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/prasanjit-dey-ux/insposite.git
   ```

2. **Install dependencies:**

    ```bash
    npm install
    # or
    pnpm install
    ```
3. **Start the development server:**
    ```bash
    npm run dev
    ```


4. Open http://localhost:3000 with your browser to see the result.
